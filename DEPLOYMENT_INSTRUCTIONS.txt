## 🚀 Quick Start Guide

### Step 1: Extract the Files

1. Locate the downloaded `nikhil-portfolio.zip` file
2. Extract it to a location on your laptop (e.g., `Documents/Projects/`)
3. You'll see a `frontend` folder with all files

---

### Step 2: Install Prerequisites

Before you start, make sure you have:

**Node.js** (version 14 or higher)
- Check if installed: Open Terminal/Command Prompt and run: `node --version`
- If not installed, download from: https://nodejs.org/ (Choose LTS version)

**Yarn** (package manager)
- Check if installed: `yarn --version`
- If not installed, run: `npm install -g yarn`

**Git** (for deployment)
- Check if installed: `git --version`
- If not installed, download from: https://git-scm.com/downloads

---

### Step 3: Open Terminal/Command Prompt

**On Windows:**
- Press `Win + R`, type `cmd`, press Enter
- Or search for "Command Prompt" in Start Menu

**On Mac:**
- Press `Cmd + Space`, type "Terminal", press Enter
- Or find Terminal in Applications → Utilities

**On Linux:**
- Press `Ctrl + Alt + T`
- Or find Terminal in your applications

---

### Step 4: Navigate to Your Project

```bash
# Replace with your actual path where you extracted the files
cd Documents/Projects/frontend

# On Windows, it might be:
# cd C:\Users\YourName\Documents\Projects\frontend
```

---

### Step 5: Install Dependencies

This will download all required packages (will take 2-3 minutes):

```bash
yarn install
```

Wait for it to complete. You should see "success" messages.

---

### Step 6: Test Locally (Optional but Recommended)

Before deploying, let's make sure everything works:

```bash
yarn start
```

This will:
- Start a development server
- Automatically open http://localhost:3000 in your browser
- Show your portfolio

**Test checklist:**
- ✓ Hero section displays your name
- ✓ Navigation works (click menu items)
- ✓ All sections scroll smoothly
- ✓ Contact form appears
- ✓ Everything looks good on mobile (resize browser window)

**To stop the server:** Press `Ctrl + C` in the terminal

---

### Step 7: Deploy to GitHub Pages

Now let's make your portfolio live!

#### 7.1: Initialize Git

```bash
git init
git add .
git commit -m "Initial commit: Portfolio website"
```

#### 7.2: Connect to GitHub

```bash
git remote add origin https://github.com/NikhilAg2021/NikhilAg2021.github.io.git
git branch -M main
```

#### 7.3: Push to GitHub

```bash
git push -u origin main
```

**If it asks for authentication:**
- Username: `NikhilAg2021`
- Password: Use a **Personal Access Token** (NOT your GitHub password)

**To create a Personal Access Token:**
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name it: "Portfolio Deployment"
4. Select scope: `repo` (check all repo boxes)
5. Click "Generate token"
6. **Copy the token immediately** (you won't see it again!)
7. Use this token as your password when pushing

#### 7.4: Deploy to GitHub Pages

```bash
yarn deploy
```

This will:
- Build your optimized website
- Create a `gh-pages` branch
- Push it to GitHub
- Your site will start deploying!

---

### Step 8: Configure GitHub Pages

1. Go to: https://github.com/NikhilAg2021/NikhilAg2021.github.io/settings/pages
2. Under **"Source"**:
   - Branch: Select `gh-pages`
   - Folder: Select `/ (root)`
3. Click **"Save"**

---

### Step 9: View Your Live Portfolio! 🎉

Your portfolio will be live at:

**🌐 https://NikhilAg2021.github.io**

⏱️ **First deployment takes 5-10 minutes**. After that, check the URL!

## ❌ Troubleshooting

### Issue: "yarn: command not found"
**Solution:** Install Yarn
```bash
npm install -g yarn
```

### Issue: "node: command not found"
**Solution:** Install Node.js from https://nodejs.org/

### Issue: "Port 3000 is already in use"
**Solution:** Kill the process or use a different port
```bash
# On Mac/Linux
lsof -ti:3000 | xargs kill -9

# Or start on different port
PORT=3001 yarn start
```

### Issue: Authentication failed when pushing to GitHub
**Solution:** Use a Personal Access Token instead of password (see Step 7.3)

### Issue: Deployment succeeded but site shows 404
**Solution:** 
1. Wait 5 minutes
2. Check GitHub Pages settings (Step 8)
3. Ensure `gh-pages` branch exists on GitHub
4. Clear browser cache and try again

### Issue: Site shows blank page
**Solution:** Check `package.json` - the `homepage` field should be:
```json
"homepage": "https://NikhilAg2021.github.io"
```
